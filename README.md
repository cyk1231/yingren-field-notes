# 影刃风物志 · 随身笔记 / Yingren Field Notes

《影之刃零》离线图鉴、地图与攻略伴侣。Nexus Mods 下载不可用时的公开镜像。

**下载：** [GitHub Releases](https://github.com/cyk1231/yingren-field-notes/releases/latest)

> 当前版本：1.1.0 · Windows 10/11 x64 · 约 175 MB

## 这是什么

一个独立的 Windows 桌面伴侣，由「影刃风物志·全攻略百科」小程序内容打包而成。包含全图鉴、11 张地图 / 1,322 个点位、书籍与全对话、任务、成就、美术与音乐封面。

它**不修改游戏**，**不注入代码**，**不需要 UE4SS、BepInEx 或任何 Mod 加载器**。只是一个普通桌面窗口，可置顶、可缩到托盘。

## 内容

- 1,136 条图鉴，含 74 条铸魂素材
- 611 条收集图鉴，11 张地图 / 1,322 个点位
- 22 本书 / 218 页可读正文，63 场 / 4,910 句全对话
- 65 个任务，66 项成就
- 146 幅美术原画，66 首音乐封面
- 杀气琥珀 / 黑石、Boss / NPC / 任务点位与全屏地图

## 安装

1. 下载 `Yingren-Field-Notes-1.1.0-win-x64.zip`。
2. 解压到任意文件夹，例如 `D:\Games\YingrenFieldNotes`。
3. 运行 `Yingren Field Notes.exe`。

保持文件夹结构完整，不要直接在压缩包里运行 EXE。无需安装器，不触碰游戏目录。

Windows SmartScreen 可能提示“未知发布者”，因为 EXE 未签名；确认来源后可选择“更多信息 → 仍要运行”。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+Shift+Y` | 显示 / 隐藏窗口 |
| `Ctrl+Shift+P` | 切换置顶 |
| 托盘图标 | 显示 / 隐藏、置顶、重载、退出 |

默认置顶。关闭窗口会缩到托盘，可从托盘菜单或 `Ctrl+Shift+Y` 找回。建议游戏使用无边框 / 窗口模式；独占全屏可能挡住桌面悬浮窗。

## 数据与隐私

- 进度与地图勾选只保存在本机。
- 离线版不启用云存档同步；可用应用内“导出”备份 JSON。
- 应用界面为简体中文，数据基于《影之刃零》中文版。
- 卸载：删除解压文件夹，并删除 `%APPDATA%\yingren-field-notes`。
